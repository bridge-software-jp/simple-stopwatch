# Simple StopWatch（シンプル・ストップウォッチ）

名前のまんま、非常にシンプルなストップウォッチです。Windows用フリーソフトです。

> **A very simple stopwatch for Windows — nothing more.**

## 使い方

- **開始** … 測定を開始します
- **停止** … 測定を一時停止します
- **再開** … 測定を再開します
- **消去** … 測定時間を消去し、初期状態に戻します

## 便利機能

1. 背景色や文字色を自分好みにカスタマイズできます
2. 他のアプリケーションの後ろに隠れないよう設定できます（常に手前に表示）
3. アプリ全体の透過度を変更できます

## 動作環境

- Windows 10 / 8 / 7 / Vista（x64）
- フリーソフトです
